# zine-rack

This web app is basically a magazine rack but in a digital space, for digital zines. The layout will be a zero perspective magazine rack (like what you'd expect at a news stand but with no perspective). The magazines on the rack will be clickable and will open up to different pages where you can flip through the magazines.

This project is an excuse to fiddle with the react-pageflip and react-pdf packages.
